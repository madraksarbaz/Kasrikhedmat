# بسته سئوی Kasrikhedmat

این بسته یک نسخه ایستای قابل انتشار برای GitHub Pages است.

## محتویات
- `index.html`: صفحه اصلی و فهرست خدمات
- `pages/`: 28 صفحه جداگانه برای موضوعات نظام وظیفه
- `assets/style.css`: استایل راست‌چین و واکنش‌گرا
- `robots.txt` و `sitemap.xml`: فایل‌های پایه خزش و نقشه سایت

## روش بارگذاری
1. از مخزن فعلی GitHub یک نسخه پشتیبان بگیر.
2. فایل ZIP را باز کن.
3. محتویات پوشه `Kasrikhedmat_SEO_Package` را در ریشه مخزن `Kasrikhedmat` بارگذاری کن؛ به‌گونه‌ای که `index.html` در ریشه مخزن باشد.
4. تغییرات را Commit کن.
5. پس از انتشار، این نشانی‌ها را بررسی کن:
   - https://madraksarbaz.github.io/Kasrikhedmat/
   - https://madraksarbaz.github.io/Kasrikhedmat/robots.txt
   - https://madraksarbaz.github.io/Kasrikhedmat/sitemap.xml
6. در Google Search Console دامنه/آدرس را ثبت کن و `sitemap.xml` را ارسال کن.

## نکات مهم پیش از انتشار
- شماره واتساپ در این نسخه از شماره درج‌شده در اطلاعات قبلی سایت استفاده می‌کند: 09306805034. حتماً مالکیت و فعال بودن آن را تأیید کن.
- آدرس canonical و sitemap برای GitHub Pages فعلی تنظیم شده‌اند. اگر نام مخزن یا دامنه عوض شد، همه URLها باید اصلاح شوند.
- محتوای صفحات، متن اطلاع‌رسانی عمومی و اولیه است؛ قبل از انتشار نهایی، هر صفحه را با مقررات روز و منابع رسمی تطبیق بده و مطالب اختصاصی، مثال‌های واقعی و تاریخ بازبینی اضافه کن.
- درباره «خرید خدمت» هیچ ادعای فعال بودن طرح نشده است؛ وضعیت آن باید فقط بر اساس اطلاعیه رسمی روز بیان شود.
- برای موضوعات بهزیستی و کمیته امداد، تحت پوشش بودن به‌تنهایی به معنی معافیت قطعی نیست.
- از شماره ماده قانونی بدون بررسی متن رسمی قانون و اصلاحیه‌ها استفاده نکن.
- meta keywords عمداً درج نشده؛ گوگل از این متا برای رتبه‌بندی استفاده نمی‌کند. کلمات کلیدی در عنوان، توضیحات و محتوای طبیعی صفحات به‌کار رفته‌اند.
- صفحه‌های اختصاصی در این بسته نقطه شروع‌اند؛ برای سئوی رقابتی باید محتوای مفید، دقیق، منحصربه‌فرد و به‌روز توسعه یابد.
